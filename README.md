# CodeArena 

A complete Vite + React frontend for an institutional coding platform.

## Included role experiences

### Student
- Dashboard
- Contests
- Contest details
- Problem library
- Monaco coding IDE
- Code playground
- Leaderboard
- Submission history
- Performance analytics
- Profile
- Settings

### Faculty
- Faculty dashboard
- Exam/contest management
- Problem bank
- Student performance
- Live assessment monitor
- Faculty analytics

### Administrator
- Platform dashboard
- Users & role governance
- Institution-wide contests
- Master problem bank
- Audit & security
- Platform analytics
- System settings

## UI
- Premium SaaS/developer aesthetic
- Dark theme
- Light theme
- Theme switcher
- Responsive desktop/tablet/mobile layouts
- Charts and analytics
- Monaco editor
- Mock data
- Role-aware navigation
- Interactive filters, tabs, forms and simulated code execution

## Deployment
This is a frontend demo. It does not require a backend for the included experience.
Upload the folder to GitHub and import the repository into Vercel. Vercel will detect Vite.
